Droits d'auteur

Les droits d'auteur protègent les œuvres originales (musique, art, livres). Le titulaire a le droit exclusif de copier, distribuer et afficher l'œuvre. Les droits d'auteur ne protègent pas les faits, idées, noms, titres ou slogans. Des exceptions existent dans certains pays (critique, révision, parodie).

Comment signaler une violation

Si vous êtes titulaire de droits d'auteur (ou leur mandataire) et pensez qu'un contenu disponible via le Service Namyo enfreint votre œuvre, soumettez un avis via le formulaire web ou contactez :

Votre réclamation doit contenir :

  • L'identification précise de chaque œuvre dont la contrefaçon est alléguée ;
  • Une description de l'emplacement du contenu litigieux sur le Service Namyo (URL si possible) ;
  • Vos coordonnées complètes (nom, adresse, téléphone, email) ;

Section 3

Marques de commerce

Une marque de commerce (mot, slogan, symbole ou dessin) distingue les produits ou services d'une entité des autres. Elle vise à prévenir la confusion des consommateurs quant à l'origine d'un produit ou service.

Si vous êtes titulaire d'une marque (ou son mandataire) et pensez qu'un contenu sur le Service Namyo l'enfreint, soumettez un avis via le formulaire web dédié. My Sonar peut transmettre vos coordonnées à la partie présumée en faute.

Section 4

Traitement des réclamations

My Sonar examine les réclamations reçues, évalue et prend les mesures appropriées (suppression de contenu, désactivation dans certains pays). My Sonar peut communiquer avec le demandeur et l'utilisateur concerné. Tout contenu enfreignant des droits peut être supprimé, et les contrevenants répétés peuvent voir leur compte résilié.

Si vous estimez que votre contenu a été traité par erreur, vous disposez d'une procédure de recours détaillée dans la correspondance électronique de My Sonar. My Sonar exploite également une combinaison de signaux automatisés et manuels pour détecter les violations.
